🔧 Интеграция между GlobalCoin (GLC) смарт-контракт и DAO за автоматизирано управление
За да свържем смарт-контракта на GlobalCoin с DAO-то за управление, ще използваме:
✅ Смарт-контракт за автоматично разпределение на такси (например 10% от транзакциите отиват в DAO-то).
✅ Функция за гласуване в DAO-то, която да управлява тези средства.

📌 Част 1: Автоматизирано разпределение на такси към DAO-то
Ще модифицираме GlobalCoin смарт-контракта, за да изпраща 10% от транзакциите към DAO-то.

🔧 Код за смарт-контракта (Solidity)
solidity
============================================================================================

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";
import "@openzeppelin/contracts/access/Ownable.sol";

contract GlobalCoin is ERC20, Ownable {
    uint256 public constant MAX_SUPPLY = 1_000_000_000 * 10**18; // 1 милиард токена
    uint256 public transactionFee = 1; // 1% такса за транзакции
    address public daoAddress; // Адрес на DAO-то за разпределение на такси

    constructor(address _daoAddress) ERC20("GlobalCoin", "GLC") {
        _mint(msg.sender, MAX_SUPPLY);
        daoAddress = _daoAddress; // DAO-то получава адреса за разпределение
    }

    // Функция за промяна на таксата (само от собственика)
    function setTransactionFee(uint256 _newFee) external onlyOwner {
        require(_newFee <= 5, "Таксата не може да надвишава 5%");
        transactionFee = _newFee;
    }

    // Функция за промяна на адреса на DAO-то
    function setDaoAddress(address _newDaoAddress) external onlyOwner {
        daoAddress = _newDaoAddress;
    }

    // Функция за изпращане на токени с такса (ако е активирана)
    function transferWithFee(address recipient, uint256 amount) external returns (bool) {
        uint256 fee = (amount * transactionFee) / 100;
        uint256 amountAfterFee = amount - fee;

        _transfer(msg.sender, recipient, amountAfterFee);
        _transfer(msg.sender, daoAddress, fee); // Таксата отива при DAO-то

        return true;
    }

    // Функция за изпращане на токени към DAO-то (без такса)
    function sendToDao(uint256 amount) external onlyOwner {
        _transfer(msg.sender, daoAddress, amount);
    }
}
(Този код изпраща 1% от транзакциите към DAO-то по подразбиране. Можете да промените процента.)

За да управлявате GlobalCoin (GLC) средствата в DAO-то, ще използваме Aragon с Token Voting.

🔧 Как да настроим гласуване за разпределение на средства?
Влезте в Aragon DAO-то и отидете в Proposals.
Създайте ново предложение със следния формат:
markdown


### Предложение: Разпределение на средства от GlobalCoin такси

**Описание:**
Да се разпределят **10,000 GLC** (получени от такси) за:
- **Маркетинг** (5,000 GLC)
- **Разработка** (3,000 GLC)
- **Резерв** (2,000 GLC)

**Гласуване:**
- **За** → 1 GLC = 1 глас
- **Против** → 1 GLC = 1 глас

**Краен срок:** 7 дни
DAO-то ще гласува и ако предложението мине, средствата автоматично ще бъдат прехвърлени.

📌 Част 3: Хардуерна интеграция (Hardhat скрипт за автоматизация)
Ако искате автоматично да изпращате такси към DAO-то, можете да използвате Hardhat скрипт.

🔧 Примерен скрипт за Hardhat (JavaScript)
javascript
========================================================================================

const { ethers } = require("hardhat");

async function main() {
  // Вземете контракта на GlobalCoin
  const GlobalCoin = await ethers.getContractFactory("GlobalCoin");
  const globalCoin = await GlobalCoin.deploy("0x123...YourDAOAddressHere"); // Заменете с адреса на DAO-то
  await globalCoin.deployed();

  console.log("GlobalCoin deployed to:", globalCoin.address);

  // Функция за изпращане на такси към DAO-то
  async function sendFeesToDao() {
    const [owner] = await ethers.getSigners();
    const amount = ethers.utils.parseEther("1000"); // 1000 GLC

    // Изпратете токени към DAO-то
    await globalCoin.connect(owner).sendToDao(amount);
    console.log("1000 GLC sent to DAO!");
  }

  // Извикайте функцията
  await sendFeesToDao();
}

main()
  .then(() => process.exit(0))
  .catch((error) => {
    console.error(error);
    process.exit(1);
  });
(Този скрипт изпраща 1000 GLC към DAO-то автоматично. Можете да го модифицирате за вашите нужди.)
